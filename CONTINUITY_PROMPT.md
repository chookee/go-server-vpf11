## Описание проекта

Users API — это REST API для управления пользователями, написанное на Go 1.21 с использованием чи/v5 роутера, zap logger, и SQLite базы данных. Проект реализует полный CRUD для пользователей (создание, чтение, обновление, удаление), включает пагинацию, валидацию входных данных, rate limiting, и security middleware. Все эндпоинты возвращают ответы в едином формате с timestamp, поддерживается health check для мониторинга.

Проект полностью контейнеризирован через Docker (multi-stage Dockerfile для минимального размера образа), поддерживает оркестрацию через docker-compose, и готов к развёртыванию на любом сервере с Docker. Включает 66 Go тестов (покрытие 80%+) и 18 Python автоматических тестов для проверки всех ключевых эндпоинтов. Документация включает OpenAPI 3.1 спецификацию (925 строк), подробные инструкции по запуску, Docker Hub публикацию, и CI/CD настройку.

Архитектура следует стандартам Go проектов: `cmd/` для точки входа, `internal/` для приватного кода (config, database, handlers, middleware, models, utils), dependency injection через конструкторы, context propagation для всех SQL запросов, и table-driven tests для идиоматичного тестирования. Код прошёл полный аудит безопасности: защищён от SQL injection, имеет валидацию Content-Type, ограничение размера запроса, security headers, и non-root пользователя в Docker образе.

Проект находится в статусе **Production Ready ✅**. Все базовые функции реализованы, тесты написаны, документация создана. Следующий этап — публикация в Docker Hub, развёртывание на production сервере, и опциональное добавление функций (PostgreSQL поддержка, аутентификация, мониторинг).
